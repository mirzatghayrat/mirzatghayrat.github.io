## Inside

- **Work** — apps, games and AI experiments, with project details and screenshots.
- **Experience** — career chapters, photographs and records.
- **Notes** — reflections on product decisions, AI systems and mobile growth.
- **Film** — personal videos presented in the study’s screening room.

The site is arranged as a small online study. Room transitions connect its sections, while individual pages provide direct links to projects and writing. Content is available in English and Chinese; the interface includes keyboard navigation, mobile layouts and reduced-motion support.

## About this repository

This repository contains the **compiled website published through GitHub Pages**. It is not the development-source repository and does not include an installable app or a local build setup.

The website is built with Astro and TypeScript, using static HTML, CSS, JavaScript and prepared media assets. The `main` branch serves the published output; `.nojekyll` allows GitHub Pages to serve the generated asset folders directly.

Development source, original media, drafts and local tooling are maintained separately. For an open-source project with its own source and setup instructions, see **[Arslan](https://github.com/mirzatghayrat/arslan)**.
