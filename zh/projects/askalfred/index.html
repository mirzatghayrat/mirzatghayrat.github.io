它做什么

在手机上继续 Alfred 的研究对话，并随时查看相关上下文。

它怎么运作

  1. 步骤 1提出问题

    输入研究问题，或通过语音输入表达问题。

  2. 步骤 2发送请求

    应用使用已保存的会话凭证，向 IndexWise 发起请求。

  3. 步骤 3阅读实时回复

    后端逐步传回研究事件和回复内容。

  4. 步骤 4阅读或收听

    按顺序查看结果，也可以使用独立的语音播报。

文字或语音用户输入+

在手机上用文字或语音提问。

iOS 对话SwiftUI+

按顺序呈现回复，并显示连接状态。

服务客户端URLSession · SSE+

解析事件流，区分网络数据块与完整消息。

语音界面SpeechRecognizer · VoicePlayer+

把语音转成输入，并播放回复。

访问令牌Keychain+

将登录令牌放在系统钥匙串中。

IndexWise 后端带身份验证的接口外部服务+

由后端完成研究并生成流式回复。

技术栈

SwiftUI · SwiftURLSessionSSE 事件解析Keychain 令牌存储Speech 语音框架AVFoundation 语音播放IndexWise API

IndexWise 的原生客户端；需要可用后端与账号。
