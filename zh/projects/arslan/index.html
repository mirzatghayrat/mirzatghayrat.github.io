Arslan

AI 系统 · macOS · 开源 · pre-v1

一个主代理，一支你自己带出来的团队。

开源 · Apache-2.0 · macOS · pre-v1 · v0.1.37

画面

来自真实开发版本的画面

它做什么

通过一个对话入口，组织并使用自己的 AI 专长团队。

它怎么运作

  1. 步骤 1带入资料

    在桌面对话里提出请求，同时看见回复、工具活动和需要判断的事项。

  2. 步骤 2提出问题

    主代理判断自己回答，还是把任务交给合适的专长代理。

  3. 步骤 3调用工具

    工具检索或处理信息；扫描材料可走本地文字识别，可选视觉模型有独立的数据边界。

  4. 步骤 4保留上下文

    结果回到同一个对话，本地记录和可搜索知识为下一次工作提供上下文。

你的资料文件 · 提示词+

从问题或导入的文档开始。

对话工作台React · Tauri+

在同一处查看回复、工具活动与待确认操作。

代理团队FastAPI · 工具循环+

主代理回答或委派专长代理，共用执行规则。

文档读取Apple Vision · PDFium+

提取文档文字，扫描页可走本地 OCR。

本地知识库SQLite · FTS5+

保存记录并通过全文索引找回材料。

模型与外部工具BYOK · MCP外部服务+

按用户配置调用模型与外部工具。

技术栈

React · TypeScript · ViteTauri · Rust 桌面外壳Python · FastAPIWebSocket + RESTSQLite · SQLAlchemy · FTS5Apple Vision 文字识别 · PDFium模型工具调用 · MCP

本地优先，pre-v1。外部模型与工具取决于你的配置。
