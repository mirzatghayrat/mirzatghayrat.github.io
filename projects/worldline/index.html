The product idea

The same moment, in someone else’s day.

A world clock is more useful when a time difference comes with the context of a city’s working day.

  1. Context

    Pair time with daily context

    Keep selected cities, working hours and weather together to give each clock a setting.

  2. Access

    Make checking a small action

    Bring the clocks to the app and macOS menu bar, with shared local configuration for iOS widgets.

  3. Reliability

    Respect local time rules

    Use timezone and calendar rules, including daylight saving changes, instead of a fixed hour offset.
