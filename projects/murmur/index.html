Murmur

Talk through your spending.

Let a person record spending and revisit money context through a conversation.

Captured from the development build

How it works

  1. 01

    Say it

    A user describes a purchase or asks a question.

  2. 02

    Interpret

    The model path proposes a reply and action; a fallback parser supports simpler requests.

  3. 03

    Apply the action

    The app executes a supported action and updates local ledger or memory records.

  4. 04

    Continue the conversation

    Recent messages and saved context shape the next exchange.

The product idea

A conversation that can become a record.

Use conversation to capture spending while making the step from a proposed action to a saved record visible.

  1. Input design

    Start with the person’s words

    Turn everyday spending descriptions into supported structured actions, alongside the conversation that produced them.

  2. User trust

    Separate suggestion from completion

    Validate an action before saving it locally; a generated reply alone does not mean a transaction was stored.

  3. Resilience

    Keep a smaller fallback available

    Provide a simpler local route when the agent route is unavailable, with a narrower set of capabilities.
