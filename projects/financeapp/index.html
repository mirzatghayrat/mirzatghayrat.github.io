Finance App

Everyday apps · iOS · Independent project

From a receipt to a reviewed record.

Screens

Captured from the development build

What it does

Make everyday financial records easier to capture, organize and review, including a reviewable path from an image to suggested transactions.

How it works

  1. Step 1Capture

    The user selects or captures an image; the app prepares a bounded JPEG payload.

  2. Step 2Extract a suggestion

    The provider returns structured candidate transactions from the image.

  3. Step 3Review the fields

    The user inspects amount, date, category and merchant before committing entries.

  4. Step 4Confirm & save

    Selected candidates become local transaction records.
