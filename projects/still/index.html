The product idea

A ledger with room for how life felt.

Pair everyday spending with a quiet opportunity to reflect, without making every transaction an analysis session.

  1. Core task

    Keep the daily record simple

    Record amount, category and context in a local ledger, giving reflection a concrete starting point.

  2. Rhythm

    Reflect at a weekly pace

    Use a selected week and mood context to revisit spending beyond a single transaction.

  3. Resilience

    Make AI an optional extension

    Start with local reflection rules and add a configured language model as an optional route.
