Memoria

Another way back to a photo.

Make a personal photo collection easier to browse, relate and organize through local metadata and image analysis.

How it works

  1. Choose a library

    The user selects a library source to index.

  2. Build the index

    Metadata and thumbnail services make large originals easier to browse.

  3. Find connections

    Image features support similarity, duplicate candidates and face-related grouping.

  4. Review candidates

    The user examines timelines, people, maps and candidate groups before acting.

The product idea

Find a photo through more than its date.

Use places, metadata and visual relationships as different ways into a personal photo collection.

  1. Discovery

    Offer several paths back

    Bring browsing, maps and grouping candidates together so different clues can lead to the same photograph.

  2. Precision

    Separate exact matches from resemblance

    Distinguish byte-identical files from visually similar candidates, keeping the strength of each signal clear.

  3. Traceability

    Keep the analysis traceable

    Store metadata and analysis locally, retaining feature sources when optional face models are used.
