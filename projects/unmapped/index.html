The hard parts, and what I did

Let the player discover the rule by moving.

Explore mathematical transformations through walking, jumping and carrying, using the adventure itself as the explanation.

  1. Numbers as characters, not symbols

    The problem
    If +1 is only a button, the player learns nothing. The change has to be something you can see a character live through.
    What I did
    Pip, a living 1, receives +1 on screen, visibly becomes 2, pauses, then jumps twice as far. Same character, same ink mark, same home; only the ability changes.
    Result
    The jump is a real ballistic arc computed by the core simulation, not an animation clip.

  2. Controls that don’t fight the player

    The problem
    Play-tests showed one touch grabbing the wrong thing: a ruler, a rope and a character can all sit under one finger.
    What I did
    Version 0.23 locks each touch to one target, adds slow movement and manual climbing, and stages the first new move before it is ever required.
    Result
    Each revision is frozen as its own play-test build, so feedback is always tied to a version.
