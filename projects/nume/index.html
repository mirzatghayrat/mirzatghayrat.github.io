The hard parts, and what I did

Understand a rule by changing it.

Give mathematical symbols a place in the world, where moving them changes what the player can do.

  1. Math that behaves like matter

    The problem
    The idea only works if every rule is simple, consistent and visible: a player should predict what an equation will do before pressing “=”.
    What I did
    Expressions evaluate at the “=” and drop the result to its right; a result of 0 makes a wall vanish; i turns a number 90° into a ladder. Each new rule gets a level that introduces it on its own.
    Result
    Every level declares which concepts it needs, and the build checks it.

  2. Proving every level can be solved

    The problem
    A full-state search took 70 seconds on a level with six symbols — far too slow to check 48 levels on every build.
    What I did
    Replaced it with an arithmetic-reachability check plus a bounded placement search that also looks for unintended shortcuts.
    Result
    Runs as a release gate over all 48 levels; chapter 5’s par moves are proven true minimums by an exhaustive search.
