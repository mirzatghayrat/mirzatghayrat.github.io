How it works

  1. 01

    Set the context

    The user brings a question and portfolio context into the Alfred interface.

  2. 02

    Ask Alfred

    Registered tools gather holdings, market data, analysis or external research.

  3. 03

    Read the evidence

    Tool output includes data, source and as-of fields; numeric claims are checked against available evidence.

  4. 04

    Explore further

    The answer arrives progressively with supporting context and unverified markers where needed.

The hard parts, and what I did

A research answer should show its working.

Keep a question, its portfolio context and the source of each claim close enough to examine together.

  1. An adviser that may not make up numbers

    The problem
    A language model will happily quote a fund’s return that it never looked up. In finance that is worse than no answer.
    What I did
    Every tool returns data with its source and time. A validator extracts the numbers in each answer and checks them against the tool results; anything it cannot match is marked “unverified”.
    Result
    Scored 4.98 / 5 on its own grounding evaluation (four dimensions, LLM-judged).

  2. Discipline where it matters

    The problem
    Letting a model rank funds makes the ranking impossible to audit.
    What I did
    Scoring and screening are a rule-based pipeline with no model in the loop; the adviser only explains what the pipeline found.
    Result
    A strategy backtest harness with costs included keeps the rules honest.
