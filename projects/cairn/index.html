The hard parts, and what I did

Keep the moment. Leave room to return.

A voice note holds a person’s own words. A later reflection should help revisit it without replacing that original.

  1. A journal that answers without the cloud

    The problem
    A voice journal holds the most private things a person says. Sending it to a server to be reflected on defeats the point.
    What I did
    In the release build, speech recognition, the reflection and the reply voice run on-device through Apple’s own frameworks. Remote models exist only as an opt-in tester setting.
    Result
    Native dependencies are fetched by pinned version and checksum-verified.

  2. Keep the words, not just the summary

    The problem
    AI summaries flatten how someone actually said something, which is often the part worth coming back to.
    What I did
    Original recordings and transcripts are kept. A reflection is always tied to one past moment, so it can be checked against what was really said.
    Result
    The docs state plainly what has not been shown yet: no clinical or long-term claims.
