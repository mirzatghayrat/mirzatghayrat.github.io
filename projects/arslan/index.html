What it does

Give a nontechnical person one conversation through which to shape and use a personal team of AI agents.

How it works

  1. Step 1Bring context

    The desktop surface collects the request and displays streamed text, tool activity and decision cards.

  2. Step 2Ask the host

    The host decides whether to answer directly or dispatch a specialist, using a shared tool-execution loop.

  3. Step 3Use the right tool

    Tools fetch or transform information. Scanned material can use local OCR; optional model vision has a separate data boundary.

  4. Step 4Keep what matters

    Results return to the conversation. Local records and searchable knowledge provide context for later work.
